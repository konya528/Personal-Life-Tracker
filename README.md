# Habit Log v1.4

- 「今日」タブの日付ナビゲーション（前日・日付・翌日）を独立した中央揃えのグループに変更。
- 「今日に戻る」は右側の独立領域に配置し、表示・非表示で日付ナビゲーションが移動しないように変更。
- 狭い画面では見出しと「今日に戻る」を上段、日付ナビゲーションを下段中央に配置。
- 既存の記録データ、項目設定、保存キーは変更なし。
